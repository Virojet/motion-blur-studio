# Changelog

## 1.1.0

- Keep the existing purple and graphite interface.
- Add a per-user Windows setup wizard that downloads and verifies the official
  Blur v2.45 engine when no complete installation is available.
- Add an engine-only setup launcher, portable app, runtime ZIP, source archive,
  release checksums, and repeatable GitHub build and release workflows.
- Retain preview playback recovery, direct seeking for late preview samples,
  full-clip exports, and saved user settings.

## 1.0.1

- Fix preview playback after an original clip reports a media error.
- Ignore events and playback promises from replaced players.
- Add Reload playback and preview retry controls.
- Seek directly to late preview samples while retaining surrounding frames.

## 1.0.0

- Initial desktop interface with clip queues, blur presets, real before/after
  previews, full-clip batch export, cancellation, and output validation.
